## Landlord Approval System

When someone tries to sign up or log in as a landlord:

1. Their account will be created but marked as "pending approval"
2. You'll receive an email with APPROVE/REJECT buttons
3. Clicking APPROVE allows them to access the landlord portal
4. Clicking REJECT permanently blocks their access
5. Until approved, they cannot access the landlord dashboard

The system includes:
- Database approval tracking
- Secure token-based approval links
- Email notifications with one-click approval/rejection
- Automatic blocking of unapproved landlord access

Set up your environment variables in Supabase to activate the system!
